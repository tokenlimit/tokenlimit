# 架构设计

## 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                         客户端 SDK                           │
│   Java Client  /  Python Client  /  Console (Web)            │
└───────────────────────────┬─────────────────────────────────┘
                            │ HTTP (REST/JSON)
┌───────────────────────────▼─────────────────────────────────┐
│                     tokenlimit-server                        │
│                                                             │
│  ┌────────────┐   ┌──────────────┐   ┌──────────────────┐   │
│  │ 配额管理 API │   │  限流引擎      │   │  认证 / 鉴权      │   │
│  └─────┬──────┘   └──────┬───────┘   └──────────────────┘   │
│        │                 │                                   │
│  ┌─────▼─────────────────▼───────────────────────────────┐  │
│  │               tokenlimit-common (DTO/枚举/工具)         │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
              │                          │
     ┌────────▼────────┐        ┌────────▼────────┐
     │      MySQL       │        │      Redis       │
     │  配额配置/账单    │        │  令牌桶/实时状态   │
     └─────────────────┘        └─────────────────┘
```

## 核心组件

| 组件 | 职责 |
| --- | --- |
| `tokenlimit-server` | 服务端，提供配额管理、限流、统计 API |
| `tokenlimit-common` | 共享 DTO、枚举、错误码、工具类 |
| `tokenlimit-client-java` | Java 客户端 SDK |
| `tokenlimit` (Python) | Python 客户端 SDK |
| `console` | 管理控制台前端 |

## 技术选型

- **后端**: Spring Boot 3.x / MyBatis-Plus / Redis
- **前端**: Vue 3 / TypeScript / Vite / Element Plus
- **Python SDK**: requests / cachetools
- **存储**: MySQL（持久化配置）+ Redis（运行时令牌状态）

## 设计原则

1. **多语言客户端统一协议**：所有客户端通过 REST/JSON 与 server 通信，保持一致行为。
2. **本地缓存降级**：客户端可启用本地缓存，在网络抖动时仍能进行粗粒度限流。
3. **可水平扩展**：server 无状态，令牌状态存放在 Redis，支持多实例部署。
4. **配置与运行分离**：配额配置持久化在 MySQL，运行时令牌状态在 Redis。
