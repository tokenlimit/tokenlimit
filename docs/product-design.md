# 产品设计

## 产品定位

Token Limit 是一个 **统一 Token 额度管理与配额控制平台**，帮助企业在多业务线、多语言栈下集中管理 AI/LLM 相关的 token 消耗，实现额度分配、限流、超限告警与用量统计。

## 目标用户

| 角色 | 诉求 |
| --- | --- |
| 平台管理员 | 统一管理各业务命名空间的额度配置、套餐、用量统计 |
| 业务开发者 | 通过 SDK 接入配额控制，避免单点超支 |
| 财务/运营 | 查看用量趋势，调整配额套餐 |

## 核心功能

### 1. 额度管理
- 按 **命名空间**（namespace）隔离配额，如 `product-a`、`product-b`。
- 支持 **维度**（dimension）细分，如按模型、按部门。
- 配额属性：最大 Token、补充速率（refill/s）、突发容量（burst）。

### 2. 限流控制
- 基于 **令牌桶算法**（Redis 实现），支持突发流量。
- 超限时返回明确错误码与剩余额度。

### 3. 套餐配置
- 预定义多种套餐（基础版/专业版/企业版），每种套餐含默认额度属性。
- 命名空间可绑定套餐，也可自定义覆盖。

### 4. 管理控制台
- 概览看板：命名空间数、额度配置数、累计消耗、活跃度。
- 额度 CRUD、套餐配置、用量趋势。

### 5. 多语言 SDK
- Java、Python 客户端，提供直接调用与装饰器两种接入方式。
- 支持本地缓存降级，降低服务端压力。

## 典型流程

```
管理员在控制台创建命名空间 + 配额
        │
        ▼
业务开发者使用 SDK 接入（配置 base_url + api_key）
        │
        ▼
业务调用 consume(namespace, tokens)
        │
        ▼
服务端检查 Redis 令牌桶 ──→ 充足：扣减并返回剩余
                          └── 不足：返回 4029 配额超限
```
