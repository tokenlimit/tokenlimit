快速接入
TokenLimit 提供 OpenAI Compatible API。选择你的 API Key，在 AI 客户端中完成配置即可接入。
接入配置
选择 API Key 并复制 Gateway URL，在你的 AI 客户端中完成配置。
请勿在 Cursor、DeepSeek Harness 或代码中直接配置真实 DeepSeek / OpenAI API Key。 真实供应商密钥由 TokenLimit Provider Credential 统一托管。
客户端配置示例
Cursor
DeepSeek Harness
cURL
1. 打开 Cursor Settings → Models 2. 找到 OpenAI API Key 配置项 3. Base URL 填入： https://tokenlimit.your-company.com/v1 4. API Key 填入： tl_prod_ak_8f2ka9.xxxxxxxx 5. 添加模型：deepseek-chat 6. 开启 Override OpenAI Base URL
base_url = "https://tokenlimit.your-company.com/v1" api_key = "tl_prod_ak_j92mx1.xxxxxxxx" model = "deepseek-chat"
curl https://tokenlimit.your-company.com/v1/chat/completions \ -H "Authorization: Bearer tl_prod_ak_8f2ka9.xxxxxxxx" \ -H "Content-Type: application/json" \ -d '{ "model": "deepseek-chat", "messages": [ {"role": "user", "content": "Hello TokenLimit"} ] }'

默认 1.0，可设置 1.2 表示高峰加价
如 0.5 表示 5 折，0.6 表示 6 折
支持跨天，如 22:00-次日 08:00
